HOW TO USE

使い方

画像を入れて、仕上がりを選んで、書き出す。基本はこの3つです。ここでは、それぞれの設定が何をするかと、直すための画面の使い方、うまくいかないときの確かめ方をまとめています。

  • はじめに
  • 画像を入れる
  • 仕上がりを選ぶ
  • 見比べる・動かす
  • 書き出す
  • 1ドット修正
  • キー操作
  • うまくいかないとき
  • 画像の扱い

00はじめに

  1. ① 入れるPNGを選ぶか、画面にドロップします。
  2. ② 選ぶ処理方法・大きさ・色数を決めて「ドット化する」。
  3. ③ 書き出すPNG・シート・APNG・GIF・ZIPから選んで保存。

手元に画像がなくても、「サンプルで試す」から5体の見本（ペンギンの歩き、剣士の走り、魔法使いの待機、跳ねるスライム、ネコの歩き）を読み込めます。まずこれで一通り触ってみるのがおすすめです。

01画像を入れる

  • PNG か動画（mp4・webm）を受け付けます。JPEGなどは、PNGで保存し直してから入れてください。
  • 1回に1〜64コマ。連番のときは、全コマ同じキャンバスサイズにしてください。
  • 動画や64コマを超える連番を入れると、つなぎ目の目立たない1周期を自動で選んでから読み込みます。歩き・走りは歩数で確かめます。動きの種類は「動画・長い連番から選ぶときの動き」で選べます。
  • 大きさの上限は1辺4096px・1枚419万画素までです。
  • 複数選ぶと、ファイル名の数字の順に並びます（frame-2 → frame-10 の順）。並びは後から「← 前へ」「後ろへ →」で変えられます。
  • 画面のどこにドロップしても入ります。

入ったかどうかは、入れる枠で分かります

緑の枠「✓ ○コマ入っています」入っています。寸法と、先頭から10コマの小さな見本が出ます。
赤の枠入りませんでした。理由が枠の中に出ます。前に入っていたコマはそのまま残ります。
回る印「読み込んでいます…」読み込み中です。終わるまで次の画像は受け付けません。

足すか、入れ替えるか

  • 変換する前で、同じ大きさの画像なら、今あるコマの後ろに足します。
  • 大きさが違う画像や、変換したあとに入れた画像は、前のコマと入れ替えます。

02仕上がりを選ぶ

処理方法

選択肢向いている画像
自動で見分ける画像の特徴から、下の3つのどれかを選びます。
イラストをドット化普通のイラスト（AIで作った絵など）。輪郭を見ながら、小さなキャンバスへ縮めます。
ドットの格子を整えるすでにドット絵っぽい画像。拡大されたドットの格子を見つけて、境目を整えます。
原寸を維持する大きさは変えずに、背景の透過や色数だけ整えたいとき。

迷ったら「3つの処理方法を比較」を押してください。自動・イラストをドット化・格子を整えるの3通りを並べて見せるので、良かったものを「採用」できます。

滑らかなイラストでは、自動が「格子を整える」を選んで輪郭が荒れることがありました。「イラストをドット化」・キャンバス高さ96・64色から始めると比べやすいです。

そのほかの設定

縮小の細かさ粗め / 標準 / 細かめ。「イラストをドット化」で縮めるときの細かさです。
キャンバス高さ空欄なら自動。数字（16〜512）を入れると、その高さまで縮めます。余白を含んだ高さなので、完成した絵はこれより小さくなります。
色数 / 共通パレット減色なし、または16〜256色。連番では全コマで同じ色の組を使うので、コマごとに色が揺れません。
背景自動で透過 … 背景らしい色を推定して抜きます。
グリーンバック等 … 抜く色を自分で決めます。動画生成などで緑・青・灰色の単色の下地にしたコマはこちらが確実です。
維持する … 背景を残します。服と背景の色が近くて欠けるときにも。
全コマ共通の余白を切り詰める全コマを囲む枠で切るので、コマごとの位置関係は変わりません。
透明度を0 / 255に揃える半透明のふちを、透明か不透明かのどちらかに揃えます。透ける布やガラスを残したいときは外してください。
再生速度（FPS）1〜60。確認の再生と、APNG・GIFの速さに使います。
ちらつきを消す1コマだけ色が入れ替わるドットを、前後のコマと同じ色にそろえます。動画から作った連番で効きます。1コマだけのまばたきなど、わざとの変化も消えるので、再生して確かめてください。
動画・長い連番から選ぶときの動き自動 / 歩き・走り / 待機・跳ねるなど。歩き・走りは1周期＝2歩で選びます。選んだ周期が半分（片足だけ前に出る）や長すぎるときに指定します。

03見比べる・動かす

  • 左が入れた画像、右がドット化した結果です。表示で倍率（フィット / 1・2・4・8倍）、グリッドでドットの区切り、◐で背景の明暗を切り替えます。
  • ▶ 再生で動きを確かめます。つまみを動かすと、1コマずつ送れます。
  • 下の一覧でコマを選び、「← 前へ」「後ろへ →」で順番を入れ替え、「選択を外す」で抜けます。
  • 足が滑る、顔や服が途中で変わる、ループのつなぎ目でがくっとする、はここで見つけます。

04書き出す

形式使いどころ
PNGいま表示しているコマ1枚。
シート全コマを横に並べた1枚。ゲームに取り込むならこれ。
座標JSONシートの各コマの位置（spritesheet.json）。Phaser・PixiJS がそのまま読める形式です。
APNGフルカラーのまま動く画像。見た目の確認や共有に。
GIF多くの場所で動く形式。ただし最大255色＋透明になり、時間も1/100秒単位に丸まります。
GodotGodot 4 の SpriteFrames（spriteframes.tres）。一式ZIPには、足元が原点のシーン（sprite.tscn）と、Phaser の load.aseprite で読める spritesheet-aseprite.json も入ります。
一式ZIP全コマのPNG・シート・座標JSON・Godot と Aseprite 形式のファイル・APNG・GIF・設定のJSON・ライセンスをまとめたもの。

設定のJSON（manifest.json）には、コマ数・1コマの幅と高さ・シートの並び・使った設定が入っています。

あわせて、全コマ共通の足元の基準点（geometry.pivot）と、足元のずれ・孤立した1ドットの数（quality）も入ります。足元のずれは、変換結果の上の帯にも出ます。歩き・待機で3px以上ずれていたら、一番高いコマを見直してください。

同じ変換をコマンドや AIエージェントから動かすときは、CLI・MCP・スキルを使います。今回足した機能の使い方と結果は機能の説明にあります。

051ドット修正

変換した結果の、気になる1ドットだけを直す画面です。制作画面で変換したあと、書き出しの右にある「1ドット修正 ↗」から開きます。変換結果がないまま開いた場合は、その場でペンギンの見本を変換して開くこともできます。

元の結果は上書きしません。「修正版を保存」を押すと、直したものが別の結果として作られます。

左クリックと右クリック

  • 「左クリック」「右クリック」それぞれに、道具（ペン / 消しゴム / スポイト）・色・不透明度を持たせられます。はじめは左がペン、右が消しゴムです。
  • Alt＋クリックで、押した側の色を画面から取ります。
  • 片方をスポイトにすると、取った色はペンになっているもう片方に入ります。「右で色を拾って、左で塗る」ができます。
  • X で左右を丸ごと入れ替えます。

形を崩さずに直す

  • 塗りつぶし（道具の選択肢）… 押した画素とぴったり同じ色で、上下左右につながっている範囲を塗ります。
  • 透明部分を保護（色だけ塗る）（L）… 透明なところには描かず、描いたところの不透明度も変えません。輪郭を崩さずに色だけ直せます。消しゴムは効かなくなります。
  • 複数コマを同時に直す（M）… 開始コマ〜終了コマを決めると、ペン・消しゴム・塗りつぶしが、そのコマ全部の同じ位置にも入ります。キャラクターが動かない部分（固定の小物など）を一度に直すときに。Ctrl＋Z で全コマまとめて戻ります。
  • 画面だけ左右反転（H）… 見え方だけを反転します。PNGの絵は変わりません。反転したまま描いても、正しい位置に描かれます。左右の崩れを見つけるのに使います。

範囲を選んで動かす

  1. 左か右の道具を範囲選択にして、キャンバスをドラッグします。
  2. 矢印キー（Shiftで5px）か、キャンバスの上の ← ↑ ↓ → で、選んだ部分を1pxずつ動かします。選んだ範囲の中をドラッグしても動きます。
  3. Enter（確定）で決定、Esc（取り消し）で元の位置に戻ります。Del で選んだ範囲の中身を消します。

「複数コマを同時に直す」と組み合わせると、範囲の全コマで同じ部分を同じだけ動かせます（例: 全コマの帽子を1px上へ）。確定した移動は Ctrl＋Z で1回で戻ります。

パレット

共通パレット変換で色数を減らしたときの色。減色しなかったときは選べません。
このコマの色いま開いているコマで使われている色を、多い順に最大64色。
マイパレット自分で作る色の組。このブラウザに保存されます。
  • 色見本を左クリックで左の色、右クリックで右の色にします。いま左右に入っている色には枠が付きます。
  • マイパレットは「左の色を追加」「左の色を外す」で作れます。
  • 「ファイルから読む」で .hex / .gpl / .pal / .txt を読めます。Lospec で配っているパレットはそのまま使えます。色コードを貼り付けて読むこともできます。
  • 「書き出す」で、いま表示しているパレットを .hex で保存します。

そのほかの道具

「表示するツールを選ぶ」から開きます。上の「作業セット」で、よく使う組み合わせをまとめて開けます。

座標入力X・Yを指定して1ドットに適用します。矢印キーで座標を動かし、Spaceで適用。
アニメ確認前後のコマを赤・青で重ねる（前・後それぞれ0〜3枚。離れるほど薄く）、いつも重ねるコマを緑で固定する、最初と最後のコマをつなげて比べる、足元・中心線を出す、確認用に再生する。再生したまま描けます。どれも表示だけで、PNGには入りません。
一括色変更指定したコマの範囲で、ぴったり同じ色を別の色に置き換えます。変えたくない長方形を指定できます。適用前に、どのコマの何ドットが変わるかを見て選べます。
修正の転送候補いまのコマで直前に直した内容を、ずらし量を指定して他のコマへ配る候補を出します。直す前の色がぴったり同じコマだけが候補になります。
参照画像このコマの元のイラスト（ドット化する前の画像）を、ドットの位置に合わせて横に並べるか重ねる。重ねる濃さも変えられます。修正版を保存したあとも、最初の変換結果の元画像をたどって出します（ブラウザ版は直近5件の結果まで）。
色のチェックAIの変換で混じったにじみの中間色を探して、黄色い枠で囲みます。探すのは「使われている数が少ない色（何画素以下か指定）」「似た色（差がいくつ以内なら、よく使われている方にまとめるか指定）」「パレットにない色（共通パレットかマイパレットが基準。パレットのうち使われていない色も一覧にし、マイパレットなら外せます）」。見つかったコマへ一覧から移れて、近い色に置き換える候補も出せます。置き換えは「適用前の確認」でコマごとに選びます。

元に戻す・保存

  • Ctrl＋Z で元に戻す、Ctrl＋Shift＋Z でやり直す。コマごとに直近50操作まで。
  • 編集中の内容は、このブラウザに自動で保存されます。「自動保存済み」を確かめてから閉じてください。

パソコンに保存する

左の列のいちばん下、「保存」の枠で、押す前に2つ選んでおきます。選んだ内容は次から覚えています。

パソコンの保存先ダウンロードフォルダ（ZIP）… 「pixel-motion_修正版_日時.zip」がダウンロードフォルダに入ります。
フォルダを選ぶ… 選んだフォルダの中に「pixel-motion_修正版_日時」フォルダを作って、ファイルを直接入れます。Chrome・Edge だけで使えます。ブラウザを開き直したあとの1回目は、書き込みの許可を聞かれます。
保存しない… ブラウザの中にだけ残します。
保存したあとこの画面で続ける か、制作画面へ移動して確認 するか。制作画面では、直したものを再生して確かめたり、書き出し直したりできます。

「修正版を保存」を押すと、どこに、何という名前で保存したかが画面に出ます。中身は全コマのPNG・スプライトシート・アニメーション（GIF / APNG）・設定のJSONです。

07うまくいかないとき

画像を入れても何も起きない

  • 入れる枠の色を見てください。赤い枠なら、理由が枠の中に出ています。
  • 「PNGではない」と出たら、PNGで保存し直してください。
  • 「大きすぎます」と出たら、1辺4096px以内に縮めてください。
  • 「前の処理が終わってから」と出たら、読み込みや変換が終わってからもう一度入れてください。

「大きさの違うものがあります」と出る

一度に選んだ画像の中に、キャンバスサイズの違うものが混ざっています。連番は全コマ同じ大きさにしてから入れてください。

背景が抜けない・服まで欠ける

背景と服の色が近いと、欠けることがあります。「背景」を「維持する」にするか、元の画像の背景を服に使っていない単色にしてください。

グリーンバックを抜く

  1. 「背景」をグリーンバック等にします。
  2. 1コマ目の四隅から取るを押すと、下地の色がそのまま入ります。動画生成の緑はぴったり #00FF00 ではないことが多いので、取るのが確実です。「グリーン」「放送用グリーン」「ブルー」「中性グレー」のボタンでも選べます。
  3. 許容範囲で抜き具合を調整します。キャラクターが欠けたら下げる、下地が残ったら上げる。
  4. 縁の色かぶりを消すは、輪郭のまわり2pxに残る緑みを抜きます。内側の緑の服はそのままです。緑の小物が輪郭にかかって灰色っぽくなるときだけオフにしてください。

「自動で透過」でも緑は抜けますが、輪郭に緑のふちが残りがちです。試験用のコマでは、自動だと鮮やかな緑が4コマで170画素残り、色を指定すると0画素でした。

輪郭が荒れる・黒い点が出る

処理方法を「イラストをドット化」にしてみてください。「3つの処理方法を比較」で並べて選ぶのが確実です。

歩かせると上下に跳ねる・大きさが変わる

このツールは、全コマを同じ基準で処理するので、変換でずれることはありません。ずれは元の画像にあります。コマの作り方と指示文を見てください。1枚ずつ描かせたコマは、足元が4〜5pxずれることがあります。

ドットがちらちらする

結果の帯の右側の「ちらつき」の数が多いときは、「ちらつきを消す」を入れて変換し直してください。動画から作った連番で起きやすく、見本のネコは1コマあたり36から1に減りました。

前の結果が消えた

結果はこのブラウザにだけ保存されます（直近5件）。閲覧データを消したり、別のブラウザで開いたりすると残っていません。要るものは書き出して保存してください。

「このブラウザでは動きません」と出る

Chrome・Edge・Firefox・Safari の新しい版で開いてください。

08画像の扱い

  • 変換はすべてこのブラウザの中で行われます。画像がサーバーへ送られることはありません。
  • 結果と編集中の内容は、このブラウザの中に保存されます。ほかの人からは見えません。
  • 書き出した画像は、商用利用OK・クレジット表記不要です（利用条件）。
